## SEO Competitor News Monitor – Project Description

**SEO Competitor News Monitor** is an automated system that monitors competitor news and updates from different online feeds. It collects the latest news, filters and summarizes the important information using AI, and identifies how each update may affect SEO.

The system uses **n8n automation** to collect news, process it through an **LLM (AI)**, and generate a **weekly SEO competitor intelligence report**. The final report is automatically sent to the user through **email**.

### Simple Flow

**Competitor News Feeds → Data Collection → Filtering → AI Analysis → SEO Summary → Weekly Email**

### Main Purpose

The project helps businesses:

* Monitor competitors automatically
* Save time spent checking multiple websites
* Identify important competitor and market updates
* Understand SEO opportunities and trends
* Receive all important information in one weekly email

### One-line explanation for presentation

> **“Our project automatically monitors competitor news, uses AI to analyze and summarize the updates from an SEO perspective, and sends a weekly market intelligence report through email.”**
